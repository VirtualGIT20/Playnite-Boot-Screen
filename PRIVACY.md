# Privacy

Playnite Boot Screen does not collect analytics, telemetry, account data, or credentials.

The extension stores settings and runtime files locally in Playnite's extension data directory. Optional diagnostic logs are local files only. Runtime logs are capped at 2 MiB with one backup file.

The extension itself does not make network requests. Links displayed in the manifest open the GitHub repository, issue tracker, or changelog only when selected by the user.
