## Included

- Log rotation: active log capped at 2 MiB, one backup.
- Public product name and manifest links.
- English primary README and Italian README.
- MIT license, privacy statement, third-party notices, changelog, and troubleshooting guide.
- GitHub issue and pull request templates.
- CI and tag-triggered release workflows.
- Playnite add-on database manifest templates.
- Local scripts for build, development installation, Toolbox packaging, release validation, and repository publication.

## Explicitly unchanged

- Direct Standalone readiness behavior.
- Streaming Preload/Continue behavior.
- Support for switching an already open Playnite Desktop instance to Fullscreen.
- No additional readiness delay.
- No verbose per-window diagnostic logging.
- No global emergency hotkey.
