# Security policy

## Reporting a vulnerability

For vulnerabilities that could expose user data, execute unintended commands, or weaken local system security, use GitHub's private vulnerability reporting for this repository:

1. open the repository **Security** tab;
2. select **Advisories**;
3. select **Report a vulnerability**;
4. provide a minimal reproduction and the affected version.

Do not publish sensitive details in a public issue. General bugs that do not have a security impact can be reported through the normal issue tracker.

## Supported versions

Only the latest published release is supported with security fixes.
